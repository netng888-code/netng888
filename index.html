使用說明

【更新報價】 點擊右上角「⟳ 更新報價」按鈕，即時從Finnhub抓取最新美股價格及RSI。

【RSI圖表】 點擊任何美股行，彈出視窗顯示過去30日RSI走勢圖。
RSI > 70 = 超買（紅色警示）｜RSI < 30 = 超賣（綠色機會）｜50附近 = 中性

【Barchart連結】 每行右側「↗BC」直接跳去Barchart該股頁面，可查閱盤前/盤後價、詳細圖表、期權數據。

【港股更新】 每次從券商下載最新CSV，上傳到Claude對話，請Claude重新生成此HTML檔案。

【API Key】 本檔案使用Finnhub免費API，每分鐘限60次請求，足夠日常使用。

【本地使用】 此檔案完全離線可用（API calls除外），雙擊HTML即可在瀏覽器打開，無需安裝任何軟件。

【GitHub Pages進階方法】
如想透過固定網址隨時隨地查閱（手機/平板/任何瀏覽器）：
1. 免費註冊 github.com
2. 新建Repository命名為 portfolio
3. 上傳此HTML檔案，改名為 index.html
4. Settings → Pages → 選 main branch → Save
5. 約1分鐘後獲得固定網址：yourname.github.io/portfolio
每次更新持倉，只需替換index.html即可。
